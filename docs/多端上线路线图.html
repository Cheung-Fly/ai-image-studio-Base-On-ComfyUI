AI 生图工坊 · 可选多端接入路线图

当前是本地运行的单实例个人助手；网页、小程序和桌面端是可选客户端方向，不是当前开发范围
当前定位：个人使用、单实例部署。FastAPI、Celery、Redis、SQLite、ComfyUI 和 LLM 组成一个私有助手；现有网页端已支持生图、对话、MCP 控制和偏好记忆。无需先部署公有云，也不建设多租户账号体系。将来如需手机或桌面访问，可在安全的私有网络/受保护的 HTTPS 入口下复用现有 API；新客户端只是可选扩展。

二、所有端的共同地基（只做一次）

事项具体操作说明
后端 + GPU 上云云 GPU 服务器用 docker-compose 启动 api/worker/redis，ComfyUI 常驻；llama.cpp 可同机或独立必须 不能跑在个人电脑
域名 / ICP 备案仅在选择公开互联网服务时，按部署地区和当前规定核验域名及备案要求公开上线时核验 本地或私有网络使用不需要先做公有域名部署
HTTPS远程访问时配置 TLS；优先 VPN/私有网络，或采用认证、限源的 HTTPS 反向代理远程访问时必须 不要直接暴露 ComfyUI/Redis 端口
访问保护项目已有登录/JWT；远程访问时使用 HTTPS、强口令和私有网络限制来源按需 现有认证保护个人实例，不等于多租户支持
数据库与存储升级当前 SQLite + 本地媒体目录；只有并发、备份或容量需求出现时再评估 PostgreSQL / 对象存储按需 当前个人使用不要求云端扩容
跨域 CORS只有前后端跨域部署时才配置，并仅放行确需访问的来源按部署形态配置
安全与可观测内部服务（ComfyUI/llama-server）只监听内网、密钥用环境变量、日志与错误监控必须

三、可选客户端形态（当前只维护网页端）

① 网页端

最先做，求职演示足够
  • 当前网页端由单文件 HTML/CSS/JavaScript 实现，已覆盖主要助手功能
  • 静态文件交给 Nginx 或对象存储静态网站托管
  • 本地使用默认连接当前后端；远程访问时才配置受保护的 HTTPS API 地址
  • 登录、生成进度、图库、对话/RAG、MCP 控制和个人记忆已存在
  • Vue/React 迁移属于可选维护工作，不是当前功能前置条件

② 微信小程序

复用后端，前端重写
  • 注册小程序账号，用 WXML 或 uni-app/Taro 重写页面（HTML 不能直接用）
  • 管理后台配置 request/downloadFile 合法域名（须 HTTPS+已备案）
  • 登录走微信授权 code2session
  • 学习演示：用「体验版」+ 添加体验成员（最多30人），可免正式审核跑通
  • 正式发布：须按届时小程序平台规则、服务范围和现行法规核验主体资质及备案要求

③ 桌面软件

推荐 Tauri，轻量
  • 用 Tauri（包体约 10MB）或 Electron（生态成熟、约 100MB+）把前端包成 .exe
  • 形态：客户端只做界面，连接经保护的 API；不要把 ComfyUI 或模型塞进安装包
  • 用 NSIS 做安装程序，配代码签名证书（否则 SmartScreen 拦截）
  • 可加自动更新；通过官网/GitHub Releases 分发

四、建议的演进时间线

当前 · 私有单实例助手本地 FastAPI + Celery + Redis + SQLite + ComfyUI；支持生图/视频、RAG、MCP 控制和个人偏好记忆。
V9 · 流式对话（开发中）通过 SSE 逐段显示回复；保留原 JSON 接口，兼容内置与自定义 LLM。
后续 · 可靠性维护优先完善备份、日志、错误提示和自动化回归测试，仍保持个人实例范围。
可选 · 私有远程访问确有跨设备需求时配置 VPN/私有网络或经过认证的 HTTPS 反向代理；不开放 ComfyUI、Redis 等内部服务端口。
可选 · 其他客户端只有明确需要时再评估移动端或桌面壳，共用现有 API；不作为当前发布计划。

五、合规红线（面向国内公众用户）

文生图属于「深度合成」且属于「生成式 AI」，正式对公众提供服务前：

  • 完成 ICP 备案（域名）与 生成式人工智能服务 / 深度合成算法备案（通常要求企业主体）；
  • 接入内容安全审核：提示词文本审核 + 生成图片审核（云厂商均有内容安全 API）；
  • 对 AI 生成图片添加显著标识/隐式水印（《人工智能生成合成内容标识办法》要求）；
  • 是否需要备案取决于实际服务对象、部署地区和当前法规；本页是部署规划，不构成法律意见。公开上线前应查阅主管部门最新官方要求并咨询专业人士。

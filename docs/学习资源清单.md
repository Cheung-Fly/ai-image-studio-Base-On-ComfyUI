## 三、建议学习路径（贴着项目里程碑走）

**本周（后端全链路，边跑边学）**
1. 先把项目跑通：冒烟测试 8/8 → 起 API + worker → 真实出一张图（动手优先）
2. FastAPI 官方中文「用户指南」前 1/2 + 网工狍视频对应章节 → 读懂 `main.py / api / schemas`
3. NeuralNine 的 Celery 视频 + 官方 First Steps → 读懂 `workers/`，自己口述一遍"任务怎么从 API 到 worker"
4. ComfyUI：秋叶 2~3 集补节点概念 → **API 实战视频（BV1YUozBGEGp）** → 对照官方 API 示例读懂 `comfy_client.py` 和工作流 JSON

**第 2 周（Vue 前端）**：Vue3 视频/官方文档 → 做提示词面板、参数面板、任务列表轮询、图库页

**第 3 周（实时进度/批量/图生图）**：回来看官方 API 示例里的 **WebSocket 实时进度**部分 + 批量生成视频

**第 4 周（部署）**：Docker 40 分钟视频 → 跑通 `docker compose up -d --build`

## 四、看视频的方法（避免"收藏即学会"）

- 每看完一个技术点，**在本项目里找到对应文件**，用自己的话注释一行它在干什么；
- 每学完一块，尝试改一个小东西：比如加一个 `sampler_name` 参数（贯穿 schema → workflow 模板 → ComfyUI），这是最好的理解性练习；
- 遇到报错先看 worker 终端完整 traceback，再查官方文档/视频评论区，最后来问我。
